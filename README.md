# priyankayadalla.com 🎀

**Still becoming — and that's the whole point.**

My personal site + platform — a college girl figuring it out, sharing the real journey so
other young women know they can too.

Built from scratch by **Priyanka Yadalla**.

## The pages (v1)

- **Home** — the front door: my name, the message, and a preview of everything.
- **Start Here** — new here? this is me, and where to begin.
- **About** — my story, in my own voice.
- **Journal** — a living feed: writing (dating, college, life), YouTube + TikTok videos, and
  monthly favorites, filterable by tag.
- **Connect** — say hi + follow along.

## Coming later

- **Resources / Toolkit** — my favorites + ambassador links (Princess Polly, Comfrt).
- **Q&A / Ask Me** — you ask, I answer.
- **Modeling** — portfolio + Z-card, once new photos are ready.

## Built with

Plain HTML & CSS — no frameworks, no accounts, no tracking.

## Look & feel

Soft-feminine + clean/professional. Cream & blush palette, elegant serif headlines
(Cormorant Garamond), generous whitespace.
